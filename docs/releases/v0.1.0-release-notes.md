# Castaminofen MVP Release Notes

## Executive Summary
Castaminofen v0.1.0 is the first official MVP release of the podcast platform. It delivers the core experience for authentication, podcast discovery, episode browsing, search, library flows, playlists, and playback in a mobile-first experience.

## Major Features
- User authentication and protected access
- Podcast and episode browsing
- Search experience
- Library and continue-listening flows
- Playlist support
- Player runtime with queue, repeat, and shuffle

## Known Limitations
- Session and refresh UX in the web experience can still be improved.
- Additional end-to-end coverage would strengthen regression confidence.
- Runtime hardening for network and playback edge cases remains a future improvement area.

## What’s Next
- Expand automated end-to-end testing
- Improve session refresh and resilience in the web app
- Continue hardening playback and media edge cases
