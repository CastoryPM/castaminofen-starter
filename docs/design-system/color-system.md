## Usage Rules

- Primary Purple is reserved for actions, navigation, interactive emphasis, and focus.
- Accent Green is reserved for playback, progress, playing states, counters, and success.
- Accent Purple is reserved for hover, selection, and premium emphasis.
- Olive is reserved for episode metadata and supporting chips.
