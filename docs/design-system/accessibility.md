# Accessibility Review

## Contrast

- Text and interactive surfaces should maintain WCAG AA contrast at minimum.
- Primary action surfaces should preserve visible distinction from surrounding surfaces.

## Keyboard Navigation

- All interactive elements must support keyboard focus and logical tab order.
- Focus states should use the semantic focus ring and not rely only on color change.

## Disabled States

- Disabled controls should remain readable and not disappear into the background.
- Disabled state should be communicated using both color and semantic label clarity.

## Reduced Motion

- Motion should be reduced or disabled when the user prefers reduced motion.
- No essential information should depend on animation alone.

## Screen Reader Compatibility

- Interactive elements should have clear labels.
- Toasts and status updates should use live regions where appropriate.

## Pointer Targets

- Interactive touch targets should remain at least 44px in size.
- Dense controls should avoid over-compression of spacing or hit areas.

## Color Independence

- No state should be communicated by color alone.
- Icons, labels, and text should reinforce status cues.
