# سیستم آیکون

## اندازه‌ها

- xs: 12px
- sm: 14px
- md: 16px
- lg: 18px
- xl: 24px

## Stroke Width

- default: 1.75
- active: 2
- decorative: 1.5

## قوانین

- از آیکون‌های Lucide استفاده شود.
- برای عناصر تعاملی، آیکون باید با spacing استاندارد و align-center نمایش داده شود.
- حالت hover و active باید با color token معنایی هماهنگ باشند.
- آیکون‌ها در حالت disabled با text-muted و opacity کاهش‌یافته نمایش داده شوند.
- آیکون‌های مرتبط با پخش باید از color-accent-green استفاده کنند.
