# Component States & Accessibility

## Shared States

Every interactive surface should support:
- Default
- Hover
- Pressed
- Focused
- Active
- Selected
- Disabled
- Loading
- Success
- Warning
- Danger

## Accessibility Rules

- Meet WCAG AA contrast expectations.
- Use visible focus rings for keyboard navigation.
- Avoid color-only meaning for states.
- Preserve readable contrast in both dark and light themes.
- Ensure interactive surfaces remain accessible without relying on decoration or motion alone.
