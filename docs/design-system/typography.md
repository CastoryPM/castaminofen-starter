## قواعد

- از وزن 700 فقط برای عنوان‌ها استفاده شود.
- متن بدنه باید همیشه حداقل 4.5:1 contrast داشته باشد.
- در متن فارسی، line-height کمی بیشتر از متن لاتین در نظر گرفته می‌شود.
- برای قسمت‌های metadata و caption، از spacing و رنگ ثانویه استفاده شود تا hierarchy روشن بماند.
